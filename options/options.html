Memory

CSV includes all saved jobs and current applications, regardless of the filters above.

Settings

Viewed history, browsing marks and application stages are independent. Opening a job never changes its mark or progress. Search appearances never extend retention.

Memory duration

Marks expire from their marked date; viewed history expires from the last actual opening. Expiry clears only that part of memory. Application stages and their event history never expire automatically. Records with application history remain until you explicitly remove them.

Show in search results

Select the types of jobs to show. Unselected types are hidden; a viewed job with a mark needs both selected. Applications includes Applied, Interview, Offered and Rejected. Select all four to show everything.

Maintenance

Clear expired marks and viewed history using your current settings. Unexpired information is kept.
