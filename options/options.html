Memory

Settings

Viewed history and user marks are independent. Opening a job never changes its mark. Search appearances never extend retention.

Memory duration

Marks expire from their marked date; viewed history expires from the last actual opening. Expiry clears only that part of memory. Records disappear when neither part remains.

Search filters

Any enabled filter can hide a job. Show Hidden on SEEK temporarily overrides all filters.

Maintenance

Clear expired marks and viewed history using your current settings. Unexpired information is kept.
